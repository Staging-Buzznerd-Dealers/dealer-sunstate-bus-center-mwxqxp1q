How to use it

  • Open index.html from disk — everything runs on the file protocol, no server needed.
  • Copy css/, js/ and assets/ into your project as-is. They have no interdependencies beyond the four <link> tags.
  • Port the markup into your templates block by block; the BEM class names are the contract, not the file structure.
  • Add a brand by copying one theme block in themes.css and setting four variables.

Before it ships

  • data-demo-form handlers only confirm in the browser. Point both forms at real endpoints and add server-side validation.
  • Search inputs and the href="#" links are placeholders pending real routes.
  • The save/favorite toggle holds state in aria-pressed only; it is not persisted.
  • Inventory, locations, testimonials and articles are hard-coded in the HTML. They are the shapes your data should fill.
  • Photography is the design comp's; swap in the client's licensed images before launch.
  • Building in the BuzzNerd repo rather than porting? Read docs/repo-mapping.md for where every section lives in site/.
