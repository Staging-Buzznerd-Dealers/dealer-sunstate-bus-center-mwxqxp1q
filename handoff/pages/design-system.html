Design system

Foundations & component library

Everything the dealer site is built from. Three CSS files carry the whole system: tokens.css holds the variables, components.css holds the BEM blocks below, and themes.css re-skins the whole site from a single class on <body>.

Foundations

Color

Warm and restrained. One accent family per brand; green and amber are reserved for verified and pending states and are never decorative. Do not introduce new hues — extend by adjusting the accent variables in a theme.

Space, radius, elevation

Sections run on a 96px vertical rhythm (64px on dark CTA bands, 80px on banded sections), dropping to 64px below 640px. Radius scales with surface importance. Shadow is for floating chrome only — resting cards separate with the 1px tan border instead.

Components

Button

One block, five looks, four sizes. .btn--primary and .btn--dark use the display face at 700; the rest use the body face at 600. Anchors and buttons share the class — pick the element by whether it navigates or acts.

Components

Chips, tags, badges

Chips are interactive filters and carry state in aria-pressed; the filter script sets aria-disabled="true" on any option that would return zero results, so the styling follows the ARIA rather than a separate class. Tags are static labels. The badge is the accent eyebrow above hero headlines.

Components

Forms

46px minimum control height, 1.5px tan border, 10px radius. Every field needs a label or an aria-label; placeholders are examples, never labels. Focus draws a 2px ink outline inset by 1px.

Behavior

JavaScript hooks

All behavior lives in js/site.js — no dependencies, no build step. Each behavior is opt-in through a data attribute, so markup can move into any template language without touching the script.

AttributeWhat it doesNotes
data-nav-toggleOpens the mobile panel named by aria-controlsKeeps aria-expanded in sync; closes on link click
data-dropdownHeader dropdownHover, focus-within, click (touch), Escape to close
data-quote-carouselTestimonial rotatorChildren: data-quote, data-quote-dot, data-quote-prev/next
data-carousel3dCoverflow brand/model pickerCards are data-carousel3d-item; arrows live in data-carousel3d-scope. Drag threshold 40px
data-location-filterChip filtering over location cardsChips carry data-filter-group + data-filter-value; cards carry data-<group> with |-separated values. Zero-result options are auto-disabled
data-demo-formFront-end-only confirmationMessage from data-success; replace with a real endpoint at build time
data-back-to-topReveals after 600px of scrollToggles data-visible
data-saveFavorite toggle on a listing cardState in aria-pressed; not persisted
data-yearWrites the current yearFooter copyright
data-screen-labelSection name for review and QANo behavior attached

The location filter is the one piece worth reading before you port it: it recomputes which options would return results after each change and marks the dead ones aria-disabled, so a user can never filter into an empty rail.
